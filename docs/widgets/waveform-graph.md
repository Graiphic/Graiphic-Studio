# Waveform Graph

Waveform Graph displays a complete numeric dataset. Each update replaces that
dataset; it does not accumulate a scrolling history.

| Data | Plot organization |
| --- | --- |
| One-dimensional numeric array | One plot |
| Two-dimensional numeric array | One plot per row |

Double-click the graph to edit linear axes, plot styles, and explicit initial
data. The graph's label, bounds, and visual preferences remain authored document
properties.

The current profile supports **local authoring and rendering**. Runtime
execution and advanced analysis are not yet available. The name does not imply
all waveform representations or analysis operations provided by other tools.
See [current capabilities](../reference/development-checkpoint.md).

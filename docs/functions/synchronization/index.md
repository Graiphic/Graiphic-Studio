# Synchronization functions

[All functions](../index.md)

33 operations or editor elements; 6 palette folders. Open a page to inspect its exact connector, typing rules and execution limits.

## Operations and editor elements

| Entry | Purpose |
| --- | --- |
| [Acquire Semaphore](semaphore/acquire.md) | Atomically acquires one available access or suspends only the requesting task. Timeout zero is an immediate trial, minus one is infinite, and values below minus one are invalid. Executes despite upstream error. FROG v1 reports timed_out=false on actual acquisition and preserves upstream error; an ordinary timeout adds no blocking error. |
| [Cancel Notification](notifier/cancel.md) | Clears the stored notification without invalidating the notifier or stopping pending waits. Returns the removed value, or default(T) for an empty object (FROG decision). Completed receptions stay unchanged. |
| [Create Rendezvous](rendezvous/create.md) | Creates an anonymous reusable barrier, or atomically finds the exact same-context name without resizing it. Size defaults to 2 and must be 1..INT32_MAX. Return existing prohibits creation. Upstream errors prevent allocation or lookup. |
| [Dequeue Element](queue/dequeue.md) | Removes and returns the head element in FIFO order. An empty queue waits cooperatively: -1 means no deadline, 0 an immediate attempt. Ordinary timeout is distinguished from invalidation and from a successfully received message. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Destroy Rendezvous](rendezvous/destroy.md) | Destroys the resource and all aliases, removes its name and ends pending waits with error and timed out=True. Executes cleanup despite an upstream error, which retains priority. Returns the name, no reference and no force option. Already committed successful cohorts retain success. |
| [Enqueue Element](queue/enqueue.md) | Adds one element at the tail. A full bounded FIFO waits cooperatively for space: timeout -1 waits indefinitely, 0 attempts immediately. Expiration inserts nothing. It never silently evicts an element; invalidation interrupts the wait with an error. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [First Call?](first_call.md) | Detects this node's first effective passage in its execution instance. Returns True once, then False during the same active caller cycle. No wait or initialization is performed. Unvisited branches do not consume the state; loop re-entry and pause/resume do not reset it. Shared active callers retain the same state until all release the instance; independent data spaces remain independent. This result does not mean that another branch has completed initialization. |
| [Flush Queue](queue/flush.md) | Atomically removes the present messages and returns them in FIFO order, preserving each complete message boundary even when T itself is an Array. The queue stays valid and usable; an empty FIFO returns an empty outer array. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Generate Occurrence](occurrences/generate.md) | Returns this node instance's occurrence reference. Repeated activations within the same executable instance reuse that reference. Distinct nodes and isolated instances remain independent. No payload or native address is editable. |
| [Get Notifier Status](notifier/status.md) | Reads a coherent, non-consuming snapshot: notifier name, latest uncanceled value and number of pending waits. The value is default(T) when empty; it is not a presence flag. A Multiple wait counts once per distinct watched object. |
| [Get Queue Status](queue/status.md) | Reads a coherent instant snapshot: name, capacity, count and waiting operations. Preview and dequeue both count as pending removals. Elements are returned only when requested, without removal; otherwise that output is an empty array. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Get Rendezvous Status](rendezvous/status.md) | Reads a coherent snapshot of name, current pending arrivals and participant threshold without arriving or reserving. The unchanged reference is forwarded. The snapshot may immediately become stale and cannot replace Wait. On error scalar defaults do not describe a valid resource. |
| [Get Semaphore Status](semaphore/status.md) | Returns one coherent snapshot of name, capacity, available accesses and actually suspended acquisitions without reserving or returning an access. Expired and canceled requests are removed from waiting_count. The handle is unchanged. Standard upstream-error handling applies; an invalid handle produces a diagnostic. |
| [Lossy Enqueue Element](queue/lossy_enqueue.md) | Atomically evicts the oldest element only if a bounded FIFO is full, then appends the new element without waiting. The overflow element is meaningful only when overflow? is true. Ordinary Enqueue does not use this lossy behavior. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Not A Rendezvous](rendezvous/not_a_rendezvous.md) | Returns True for a null, destroyed, stale-incarnation or foreign-context Rendezvous reference; False for a live barrier even with no arrivals. This is not a threshold test. There is no error chain or output reference. |
| [Not A Semaphore](semaphore/not_a_semaphore.md) | Returns True for a null, closed or destroyed semaphore handle; False for a live handle, including a saturated semaphore. It is not a capacity test and does not protect against a later concurrent close. No error chain or outgoing reference is part of this connector. |
| [Obtain Notifier](notifier/obtain.md) | Obtains an anonymous empty Notifier&lt;T&gt;, or an additional handle to a same-context named notifier with the exact full type. The type specimen is not sent. An absent name with create if not found=False is an error. |
| [Obtain Queue](queue/obtain.md) | Creates an anonymous FIFO when name is empty, or obtains an additional access to a same-application named FIFO with exactly the complete element type. The type specimen is not an inserted message. Capacity defaults to -1; an existing named capacity is preserved. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Obtain Semaphore Reference](semaphore/obtain.md) | Creates an independent anonymous semaphore, or obtains a distinct handle to the exact same-context name. Capacity is positive, defaults to one and never changes for an existing named resource. No access is acquired. Standard upstream-error handling prevents hidden creation. |
| [Preview Queue Element](queue/preview.md) | Returns the head element without removal or reservation. An empty FIFO waits cooperatively using timeout -1 by default. A successful preview does not prevent another consumer removing that message. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Release Notifier](notifier/release.md) | Releases this acquired handle, including with an incoming error. Other acquired handles stay usable unless this is the last one or force destroy=True. Destruction wakes pending waits with an error. Returns the name and latest value, never a notifier reference. |
| [Release Queue](queue/release.md) | Releases this obtained access, preserving independently obtained accesses unless force destroy is true. Forced destruction invalidates all accesses and wakes waits with errors. Cleanup also executes with an incoming error. Returns the FIFO snapshot before release and never returns a queue reference. Queue&lt;T&gt; is an execution resource reference; element is the ordinary T value. Public FROG target compilation remains unavailable. |
| [Release Semaphore](semaphore/release.md) | Returns exactly one acquired access and may admit one waiter. It does not close the handle. Releasing without an acquisition is an error and cannot increase availability above capacity. Executes despite upstream error and preserves it; no OS-thread ownership is imposed. |
| [Release Semaphore Reference](semaphore/release_reference.md) | Closes this handle and its aliases, interrupts only its pending acquisitions, and returns the semaphore name. Other handles survive normal close; force destroy invalidates all handles and waits. Executes despite upstream error. FROG v1 does not implicitly return already acquired accesses when another handle keeps the resource alive. |
| [Resize Rendezvous](rendezvous/resize.md) | Atomically adds the signed size change to the current threshold; it is a delta, never an absolute size. FROG releases the entire current cohort if the lower threshold is satisfied. Nonpositive or overflowing results leave state unchanged. Upstream errors skip mutation. |
| [Send Notification](notifier/send.md) | Atomically publishes one typed notification and wakes eligible waiting readers. Replaces the previous value instead of enqueueing it. Equal values sent twice remain distinct emissions; every reader has its own reception state. |
| [Set Occurrence](occurrences/set.md) | Signals the supplied occurrence and makes its pending waiters eligible to resume. No application data is transferred and no acknowledgement is awaited. This is an effect even without an output terminal. An invalid reference cannot signal another resource and is diagnosed. |
| [Wait at Rendezvous](rendezvous/wait.md) | Registers this call once in the current generation and suspends only this task until the threshold, timeout, destruction or cancellation. A completed cohort cannot release a later generation. Upstream error skips arrival and returns timed out=True. FROG timeout 0 tests arrival immediately; -1 has no deadline. |
| [Wait on Notification](notifier/wait.md) | Waits for a new emission for this node instance without consuming the stored value. Ordinary waiting keeps one compact emission cursor. Ignore previous=True waits only for emissions after this call begins. Timeout -1 is unbounded, 0 polls, below -1 errors. Timed out? is also True on error. |
| [Wait on Notification from Multiple](notifier/wait_multiple.md) | Finishes when at least one watched notifier has an admissible emission. Returns matching reference/value arrays for ready distinct objects, in input order (FROG decision), not all input references. Ordinary waiting uses one compact cursor. Empty input errors. Timeout/error returns empty arrays. If T is an array, each result is wrapped in a one-field notification cluster (FROG v1). |
| [Wait on Notification from Multiple with Notifier History](notifier/wait_multiple_history.md) | Multiple wait with one cursor per object and generation, independent of array indices. Reordering or adding sources does not reset existing cursors. Finishes on any eligible source and returns matching filtered arrays. History does not archive overwritten notifications. Array-valued results use the explicit FROG v1 notification wrapper. |
| [Wait on Notification with Notifier History](notifier/wait_history.md) | Wait with an independent emission cursor for each notifier object and generation encountered by this node instance. A/B/A preserves both cursors. History tracks sources, not all past messages; overwritten values cannot be recovered. The other single-wait ports and timeout/error rules are unchanged. |
| [Wait on Occurrence](occurrences/wait.md) | Suspends this execution path until an eligible signal arrives or the wait expires. An invalid reference returns timed out immediately. Timeout is signed I32 milliseconds: -1 (default) waits indefinitely, 0 checks immediately, positive values set a monotonic deadline; values below -1 are controlled argument faults. ignore previous defaults to TRUE and ignores signals before atomic registration. FALSE accepts an unseen earlier generation for this Wait instance; acknowledged signals are not replayed and multiple signals may coalesce. This is not a FIFO. Cancellation does not publish a normal timed out result. |

## Palette folders

| Entry | Purpose |
| --- | --- |
| [Advanced Notifier](notifier/advanced.md) | Wait variants with a reception cursor per notifier object and generation. History tracks encountered sources, not a queue of previous messages. |
| [Notifier](notifier.md) | Typed latest-value notifications shared inside one runtime context. Seven operations and Advanced Notifier waits. Notifier&lt;T&gt; is distinct from Queue&lt;T&gt;; History tracks source reception cursors, not an archive of all messages. |
| [Occurrences](occurrences.md) | Generate, wait for and signal a shared Occurrence reference. A signal wakes eligible waiters without a message payload, FIFO or global consumption. Distinct Generate and Wait instances retain separate runtime identities. |
| [Queue](queue.md) | Typed FIFO resource operations. Queue&lt;T&gt; is the shared access reference, not a message or a Front Panel object reference. Each message retains its complete type. |
| [Rendezvous](rendezvous.md) | Six reusable participant-barrier operations: create, wait, resize, destroy, status and validity. Rendezvous Ref has no message type. Each successful cohort belongs to one generation; later arrivals wait for a new cohort. |
| [Semaphore](semaphore.md) | Six semaphore operations: obtain and close resource references, acquire and return counted accesses, read status and test validity. SemaphoreRef carries no message type. Reference closure and access release are distinct. |

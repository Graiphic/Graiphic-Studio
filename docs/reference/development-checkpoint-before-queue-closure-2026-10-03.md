# Historical checkpoint — early October 2026

This page records the scope of earlier editing work. Its historical versions
and validation state are superseded by [current capabilities](development-checkpoint.md).

The early October work included recursive container interaction and direct
transfer, Numeric/Enum text fitting, stable By Name field identities, boundary
tunnels, group insertion, common renaming, Waveform bound editors, adaptive
wires, and movement of mixed wire/terminal selections.

Those implementation receipts were scoped to their delivery versions. They
never established general public-source execution or a successful complete
application qualification. Later updates added normal private Run without
Highlight, Queue services, and reference workflows with their own explicit
limits.

For current user behavior, use the [Front Panel](../interface/front-panel.md),
[Block Diagram](../interface/block-diagram.md), [container guides](../widgets/index.md),
and [Run and Highlight](../interface/run-and-highlight.md).
